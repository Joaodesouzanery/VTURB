1. Leia `01-VTURB/INDEX.md` para ver os vídeos.
2. Busque o tema com Grep (sem diferenciar maiúsculas) em `01-VTURB/transcricoes/` (os `-resumo.md` são o jeito mais rápido; a transcrição inteira está no arquivo de mesmo nome sem `-resumo`), tentando sinônimos.
3. Leia as transcrições relevantes e responda com base nelas, citando título, data e link de cada fonte.
4. Se não houver base nos vídeos, diga isso; não invente. Transcrições automáticas podem errar nomes e termos.
