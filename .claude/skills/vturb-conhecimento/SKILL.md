1. Leia `INDEX.md` para ver os vídeos.
2. Busque o tema com Grep (sem diferenciar maiúsculas) em `transcricoes/`, tentando sinônimos.
3. Leia as transcrições relevantes e responda com base nelas, citando título, data e link de cada fonte.
4. Se não houver base nos vídeos, diga isso; não invente. Transcrições automáticas podem errar nomes e termos.
