# Traduzir os Produtos

> Passa o catálogo inteiro para o idioma em que a loja vende: título, tags, tipo de produto, rótulos e valores de variante, descrição reescrita, SEO, endereço do produto com redirecionamento, e uma revisão final que caça as sobras do idioma antigo.

## O que você precisa ter antes

- Shopify CLI instalado (`npm i -g @shopify/cli`) e a sua loja autenticada, com `read_products,write_products,read_files,write_files,read_online_store_navigation,write_online_store_navigation,read_publications,write_publications`. Os dois últimos são o que deixa o Passo 5 publicar as coleções novas na Loja Online; sem eles a publicação volta com acesso negado.
- A decisão de qual dos dois caminhos você quer, porque eles não são a mesma coisa:

| Você quer | Caminho |
|---|---|
| A loja vende num idioma só, e o catálogo veio em outro | Esta skill. Ela troca o texto do produto, o antigo deixa de existir |
| A loja vende em dois ou mais idiomas ao mesmo tempo | O app Translate & Adapt da Shopify, que guarda uma tradução por idioma sem apagar o original |

Se você não tiver certeza de qual dos dois é o seu caso, a skill pergunta antes de escrever qualquer coisa. Rodar o caminho errado é caro: o texto original some.

- Uma cópia de segurança do catálogo, tirada pela própria skill no primeiro passo.

## O que ela faz

| Campo | O que acontece |
|---|---|
| Título | Traduzido, com nome de modelo e nome de marca preservados |
| Endereço do produto | Regerado a partir do título novo, com redirecionamento 301 do antigo |
| Tags | Todas traduzidas |
| Tipo de produto | Traduzido |
| Descrição | Reescrita no idioma novo, com estrutura de SEO, não traduzida palavra a palavra |
| Meta title e meta descrição | Reescritos no idioma novo |
| Rótulo de opção | Cor vira Color, Tamanho vira Size, Signo vira Zodiac Sign |
| Valor de opção | Tamanhos, cores e signos convertidos |
| Alt text | Título novo e marca |
| Fornecedor | Não é traduzido |

Tamanhos: PP vira XS, P vira S, M continua M, G vira L, GG e EG viram XL, XGG vira XXL. O que estiver entre parênteses continua igual: "P (17cm)" vira "S (17cm)".

Cores: Preto vira Black, Branco vira White, Azul vira Blue, Vermelho vira Red, Rosa vira Pink, Verde vira Green, Amarelo vira Yellow, Cinza vira Gray, Marrom vira Brown, Dourado vira Gold, Prata vira Silver, Bege vira Beige, Roxo vira Purple, Laranja vira Orange. Combinação segue o mesmo padrão: "Prata/Azul" vira "Silver/Blue".

Signos: Leão vira Leo, Virgem vira Virgo, Touro vira Taurus, Gêmeos vira Gemini, Câncer vira Cancer, Escorpião vira Scorpio, Capricórnio vira Capricorn, Aquário vira Aquarius, Peixes vira Pisces.

No fim, os produtos são agrupados por tipo traduzido e as coleções são criadas e publicadas na Loja Online. Toda variante sai em "continuar vendendo sem estoque".

## Como usar

### Passo 1: acesso, idioma e cópia de segurança

Confirme para qual idioma o catálogo vai e leia a loja:

```bash
shopify store execute --store sualoja.myshopify.com --json \
  --query 'query { shop { name } products(first: 200) {
    pageInfo { hasNextPage endCursor }
    nodes { id handle title vendor productType tags status descriptionHtml
            seo { title description }
            options { name optionValues { name } } } } }' \
  > catalogo-antes-01.json
```

Loja com mais de 200 produtos repete a consulta trocando `products(first: 200)` por `products(first: 200, after: "<endCursor da página anterior>")`, uma página por arquivo, até `hasNextPage` vir `false`. O teto de 200 existe porque a Shopify recusa consulta acima de 1.000 pontos e cobra por objeto pedido, não por objeto devolvido.

### Passo 2: traduzir

A skill percorre o arquivo e escreve a versão nova de cada campo. Duas regras de conteúdo pesam aqui:

- Nome de modelo e nome de marca não se traduzem. "Compass Rose" é tradução de um nome descritivo; o nome inventado da linha continua igual.
- Acento de nome próprio é preservado. Vendôme continua Vendôme.

### Passo 3: revisão contra híbridos, antes de aplicar

Este é o passo que existe porque a tradução automática mistura os dois idiomas na mesma frase sem gerar erro nenhum:

| Sai errado | Correto |
|---|---|
| "Cat Preto Charm" | "Black Cat Charm" |
| "Eye Grego Charm" | "Greek Eye Charm" |
| "Rota Romântica Charm" | "Romantic Route Charm" |
| "Filtro dos Sonhos Charm" | "Dream Catcher Charm" |

A skill lê o texto novo inteiro de uma vez, procura título que misture os dois idiomas, corrige, e reporta quantos produtos foram corrigidos. Só depois a escrita começa.

### Passo 4: aplicar

A CLI desliga escrita por padrão: toda mutation precisa de `--allow-mutations`, e os valores entram por um arquivo JSON apontado em `--variable-file` (singular, sem "s"). O molde é sempre este:

```bash
shopify store execute --store sualoja.myshopify.com --json --allow-mutations \
  --query-file mutation.graphql --variable-file vars.json
```

Em `mutation.graphql`:

```graphql
mutation($p: ProductUpdateInput!) {
  productUpdate(product: $p) { product { id handle } userErrors { field message } }
}
```

Em `vars.json`, um produto por chamada, com `title`, `handle`, `descriptionHtml`, `productType`, `tags` e `seo`:

```json
{ "p": { "id": "gid://shopify/Product/123", "title": "Black Cat Charm", "handle": "black-cat-charm",
         "seo": { "title": "Black Cat Charm", "description": "..." } } }
```

Rótulo e valor de opção vão em `productOptionUpdate`, no mesmo molde de comando. E cada endereço trocado leva o seu redirecionamento na mesma passada, também com `--allow-mutations`:

```bash
shopify store execute --store sualoja.myshopify.com --json --allow-mutations \
  --query 'mutation {
    urlRedirectCreate(urlRedirect: { path: "/products/endereco-antigo", target: "/products/endereco-novo" }) {
      userErrors { field message }
    }
  }'
```

Se dois produtos gerarem o mesmo endereço, o segundo recebe o sufixo `-2`.

### Passo 5: imagens, alt text e coleções

Imagem convertida para WebP antes de subir, com [[15. Converter Imagens para WebP]]. Alt text depois da imagem, nunca antes. Coleções criadas por tipo de produto traduzido e publicadas na Loja Online. Coleção que ficou vazia é apagada.

### Passo 6: revisão final, e ela é bloqueante

O catálogo é lido de novo, direto da loja, e a tradução só é dada por concluída com:

1. zero título com palavra do idioma de origem;
2. zero título misturando os dois idiomas;
3. zero endereço de produto com palavra do idioma de origem;
4. zero rótulo de opção no idioma antigo.

Item que falhar volta para correção e a leitura recomeça. Entregar com pendência aqui é o erro que a skill existe para evitar. Para rodar essa mesma conferência em qualquer momento futuro, use [[104. Varredura de Idioma do Catalogo]].

## O que ela devolve

- `catalogo-antes-01.json` e seguintes, uma por página lida, a cópia do catálogo no idioma antigo.
- O catálogo traduzido na loja.
- A contagem de produtos corrigidos na revisão contra híbridos.
- A tabela dos endereços trocados, com o redirecionamento de cada um.
- A lista das coleções criadas e das apagadas.
- O resultado das quatro conferências finais, item por item.

## Onde erra

**Esperar loja bilíngue e receber o catálogo trocado de idioma.** Esta skill reescreve o produto base. O texto em português deixa de existir, e o cliente que chegar por um anúncio em português lê inglês. O sinal aparece na hora: o seletor de idioma mostra o mesmo texto nos dois idiomas. Voltar atrás exige a cópia de segurança do Passo 1.

**Pular a revisão contra híbridos.** "Cat Preto Charm" não gera erro técnico, entra na loja, roda no anúncio e só é notado por um cliente. É o único passo que pega esse defeito.

**Traduzir o título e esquecer o endereço.** O produto aparece como "Black Cat Charm" e a URL continua com a palavra em português. Procure termos do idioma antigo dentro dos endereços, não olhe só a vitrine.

**Trocar o endereço sem criar o redirecionamento.** Pela API, mudar o `handle` não cria 301 sozinho. Todo link que já circula em anúncio, e-mail e mensagem de cliente passa a devolver 404. Confira abrindo um endereço antigo numa janela anônima.

**Traduzir valor de variante que outra coisa usa.** Coleção automática filtrando por "Preto", regra de desconto, app de provador e metafield que casa pelo texto exato param de funcionar quando o valor vira "Black". Antes de traduzir valores, procure onde eles são citados.

**Traduzir nome de marca ou de modelo.** O nome vira outra coisa, o cliente não reconhece o produto do anúncio e a busca interna da loja para de achar.

**Descrição reescrita com promessa que a operação não cumpre.** Prazo de entrega e garantia inventados na reescrita viram disputa depois. Só entra na descrição o que a sua loja sustenta.

**Rodar a tradução com o SEO já escrito no idioma antigo.** O trabalho de SEO é jogado fora. Traduzir primeiro, [[06. Gerar SEO dos Produtos]] depois.
