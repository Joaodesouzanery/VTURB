# 10. Especialista do Tema Dawn

> Descobre qual seção do seu tema resolve o que você quer, e quando o tema não tem, escreve uma seção nova inteira controlável pelo editor, sem você precisar mexer em código depois.

## O que você precisa ter antes

- O tema baixado na máquina, ou o Shopify CLI autenticado na loja para baixar (`shopify theme list`, `shopify theme pull`).
- Saber em qual tema você está: o alvo desta skill é o Dawn e os temas derivados dele. Tema pago de terceiro funciona, mas o código dele não pode ser distribuído, então a leitura é sempre no seu próprio arquivo.
- Um lugar seguro para testar: uma cópia do tema, nunca o que está publicado.

## O que ela faz

Trabalha em três frentes, nesta ordem:

**Descobre qual tema está rodando.** Pelo arquivo, pelo nome das seções ou pelo HTML público da loja, sem depender de você saber a resposta.

**Aponta a seção certa.** Diz o nome exato dela no tema, onde encontrar no editor, quais ajustes configurar e quais blocos adicionar. Quando o tema tem algo parecido mas não igual, aponta a mais próxima e como configurar para chegar no resultado.

**Escreve a seção nova quando não existe.** Liquid completo, com schema, presets, CSS responsivo e todos os controles no editor. A regra é que depois de instalada você nunca mais precise abrir o código: toda opção visual vira um ajuste no editor. Toda seção nova nasce com versão para computador e versão para celular, em dois grupos separados no schema.

Três seções já vêm prontas no motor, escritas para tema Online Store 2.0, sem script, sem Node, sem Python e sem chave de API. Nenhuma delas edita `theme.liquid`, `base.css` ou o JS principal, e todo o CSS é escopado dentro do próprio arquivo:

| Arquivo | Nome no editor | Para que serve |
|---|---|---|
| `category-circles.liquid` | Category Circles | Grade de categorias em círculo, com controle de tamanho |
| `collections-slider.liquid` | Collections Slider | Slider horizontal com as coleções da loja |
| `utility-header-bar.liquid` | Utility Header Bar | Barra de links acima da faixa de avisos |

As três são anteriores a essa regra e não cumprem ela inteira. `category-circles` e `collections-slider` têm ajuste de celular (`circle_size_mobile`, `gap_mobile`, `mobile_visible`), só que misturado nos grupos de tamanho e de layout, não num grupo Mobile separado. A `utility-header-bar` não tem ajuste de celular nenhum: ela simplesmente some abaixo de 749 px, e isso está fixo no CSS dela. Antes de publicar qualquer uma das três, abra no celular.

## Como usar

### Passo 1. Descobrir o tema

Pelo CLI, para saber qual está publicado:

```bash
shopify theme list --store {handle}.myshopify.com
```

Com o tema baixado, o autor sai do próprio arquivo de configuração:

```bash
head -20 config/settings_schema.json
```

As duas primeiras linhas úteis do arquivo são `theme_name` e `theme_author`.

Autor vazio e presença de `sections/image-banner.liquid` sem seções exóticas ao lado é Dawn. Tema derivado do Dawn mantém as mesmas variáveis de cor, então tudo escrito para Dawn instala sem adaptação.

Sem acesso ao arquivo, dá para ler pelo HTML público: as classes começam com `shopify-section--` seguido do nome da seção, e os nomes das seções exclusivas entregam o tema.

### Passo 2. Classificar o pedido

| Situação | O que acontece |
|---|---|
| O tema já tem a seção | você recebe o nome, o caminho no editor e os ajustes recomendados |
| O tema tem algo parecido | você recebe a mais próxima e como configurar para chegar perto |
| O tema não tem | escreve-se uma seção nova (passo 3) |
| Você viu numa loja e quer igual | identifica-se o equivalente no seu tema, e se não houver, escreve-se |

Para achar o que o tema tem, o caminho é ler a pasta, não adivinhar:

```bash
ls sections/ | sort
grep -l "image_picker" sections/*.liquid
```

### Passo 3. Instalar uma das seções prontas

Pelo admin, sem baixar nada:

1. Online Store, Themes, botão de três pontos, Edit code.
2. Em `Sections`, clique em **Add a new section**, dê o mesmo nome do arquivo (sem `.liquid`) e cole o conteúdo inteiro por cima do que o editor criar.
3. Volte ao Customizer, **Add section**, e ela aparece pelo nome do preset.

Pela linha de comando, com o tema baixado:

```bash
cp "_engine/theme-sections/category-circles.liquid" sections/
shopify theme push --only sections/category-circles.liquid --store {handle}.myshopify.com
```

### Passo 4. Quando a seção é escrita do zero

O que é obrigatório em toda seção nova:

- Toda opção visual tem um ajuste no schema. Nada de cor ou medida escrita direto no Liquid.
- Conteúdo que se repete (item de lista, slide, coluna) vira bloco, com `{{ block.shopify_attributes }}` no elemento raiz de cada um, senão o bloco não se move no editor.
- `presets` com pelo menos um item, senão a seção não aparece na lista de adicionar.
- Dois grupos no schema, um "Desktop" e um "Mobile", com os ajustes duplicados e o CSS trocando por variável numa media query de 749px.
- Cores e fontes vindas das variáveis do tema, não escritas na mão.
- Classe com prefixo próprio em todos os elementos, para o CSS não vazar para o resto do tema.
- Texto passado por `escape` onde não for campo de texto rico.

### Passo 5. Conferir antes de publicar

```bash
shopify theme check --path .
```

Depois, abra o editor na cópia do tema e confirme três coisas: a seção aparece na lista de adicionar, os ajustes estão separados em Desktop e Mobile, e mudar cada ajuste muda o preview.

## O que ela devolve

- O nome do tema que está rodando na loja, com a evidência de como foi identificado.
- A seção recomendada, com o caminho no editor, os ajustes a configurar e os blocos a adicionar.
- Quando o tema não tem: o arquivo `.liquid` completo, pronto para colar em `sections/`, mais as instruções de instalação e a lista dos controles que você ganha no editor.

## Onde erra

**A seção não aparece no editor.** É schema com JSON quebrado, quase sempre uma vírgula sobrando antes de um fecha-chaves ou uma aspa faltando. O editor não mostra erro: a seção simplesmente não está na lista.

**A seção aparece mas não dá para adicionar.** Faltou `presets` no schema. Sem preset, a seção existe no arquivo e nunca aparece em "Add section".

**O bloco não se move no editor.** Falta `{{ block.shopify_attributes }}` no elemento raiz do bloco. Você percebe quando arrastar não funciona e clicar não seleciona.

**O CSS da seção nova quebra o resto do tema.** Classe genérica demais (`.card`, `.grid`, `.title`) colide com a do tema. Prefixe tudo com o nome da seção.

**Ajuste de intervalo recusado sem aviso.** A Shopify limita o intervalo a 101 passos. `min:0 max:200 step:1` dá 201 passos e é rejeitado calado: o schema inteiro deixa de carregar. Suba o `step`.

**Div vazio some.** O `base.css` do Dawn tem uma regra que esconde elemento vazio. Camada visual sem conteúdo (scrim, overlay, degrade) precisa de `display: block` declarado na própria regra, senão ela tem o fundo certo e não renderiza, sem erro nenhum no console.

**O push diz sucesso e o arquivo não mudou.** Acontece com push em lote. Confirme lendo o arquivo de volta da loja, não pelo texto do CLI. Push de um arquivo por vez, com pausa entre eles, é mais lento e mais confiável.

**Editar `layout/theme.liquid` ou `assets/base.css`.** Esses dois arquivos envelopam a página inteira e carregam dependências invisíveis, inclusive coisas que parecem gambiarra e sustentam transições. Otimização que parece objetivamente melhor derruba o tema e a página fica em branco. Se algo precisa mesmo ir para lá, faça numa cópia não publicada, compare lado a lado e só então promova.

**Mexer no tema publicado.** Toda alteração vai para uma cópia. Publicar é o último passo, depois de olhar o preview.
