# Theme Clone (PDP) — Sumário Executivo

> Documento de referência rápida. Para detalhes técnicos completos, ver 10. Shopify Theme Clone - Playbook Completo (PDP).

## O que é Theme Clone (PDP)

Workflow pra clonar páginas de produto (PDP) de uma loja Shopify pública pra outra que você opera, mantendo o layout específico por produto (template_suffix + sections customizadas) mas trocando imagens, vídeos e branding.

## Quando usar

| Cenário | Aplicar? |
|---|---|
| Loja origem é Shopify público com PDP customizado | ✅ Sim |
| Você opera uma loja Shopify destino com tema próprio | ✅ Sim |
| Quer cada produto com sua mídia específica (vídeos, imagens da origem) | ✅ Sim |
| Loja origem é Hydrogen/headless | ❌ Não — assets não acessíveis via section_id |
| Você quer só clonar catálogo (produto + variants, sem layout) | ❌ Use skill `clone-store` simples |

## Resultado do caso Luca (referência)

| Métrica | Antes | Depois |
|---|---|---|
| Produtos com template específico | 0 | 55 |
| Sections image-with-text customizadas por produto | 0 | 165 (55 × 3) |
| Vídeos vinculados | 0 | 30 |
| Imagens em Files (próprias do produto) | ~300 (galeria) | +293 (PDP sections) |
| Tempo total | — | ~50 min (sem upload manual de vídeos) |

## Pré-requisitos

1. **Custom App** na loja DESTINO com escopos: `read/write_files`, `read/write_themes`, `read/write_products`, `read/write_publications`
2. **Chrome Brain** habilitado (pra criar app via UI + validar storefront)
3. **Shopify CLI v3.94+** autenticado na loja
4. Acesso de admin na loja DESTINO

## Fluxo em 10 fases

```
1. Listar produtos da origem (handle, template_suffix)
2. Scrapear sections de cada produto via ?section_id=
3. Categorizar semanticamente (Wear/Standard/Built/Chap1/Chap2)
4. Identificar produtos com vídeo (ordem das sections muda)
5. Upload imagens via Files API (com Custom App)
6. Avisar usuário pra subir vídeos manualmente em bulk
7. Map vídeos uploaded → slug (por duração+size do MP4)
8. Gerar templates product.{slug}.json (clone do padrão + substituições)
9. Push tema + setar templateSuffix por produto
10. Validar via Chrome Brain (browser real, não curl)
```

## Top 5 armadilhas

1. **Handles com `®`** (`%C2%AE`) — sempre testar ambas variantes
2. **`.webp` vira `.png`/`.jpg`** automaticamente no upload — capturar filename real
3. **Vídeos não sobem via URL externa** — usuário sobe manual, agente mapeia
4. **Não pode renomear filename de Video** — usa alt text
5. **Cache CDN gera falsos negativos via curl** — validar via Chrome Brain

## Skills/agentes envolvidos

- `WebFetch` — Scraping HTML
- `Bash` (Python urllib) — Calls API Shopify, parsing MP4
- `shopify theme pull/push` — Sync tema
- `mcp__chrome-devtools__*` — Setup app + validação visual
