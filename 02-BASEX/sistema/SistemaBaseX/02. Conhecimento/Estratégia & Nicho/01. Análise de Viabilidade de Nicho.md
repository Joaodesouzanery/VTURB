# Análise de Viabilidade de Nicho

## Objetivo
Decidir, **antes** de investir em um nicho, se ele é viável de executar dentro do seu caixa, alcance e habilidade — usando benchmark de operações concorrentes pra entender o esforço real.

## Pré-requisitos
- [ ] Lista de candidatos a nicho (3+ opções)
- [ ] Caixa estimado disponível pra operação
- [ ] Tempo dedicado (~3 dias por candidato)
- [ ] Acesso a Google, biblioteca de anúncios do Facebook, Instagram

## Princípio guia

> **Benchmark de viabilidade ≠ benchmark de execução.** Aqui o objetivo é entender o ESFORÇO necessário pra competir, não copiar o que os outros fazem.

## Passo a passo

### 1. Coletar 10+ operações do nicho
- 3-4 marcas tradicionais (senso comum)
- 6-7 operações digitais (drop / e-commerce) bem ranqueadas no Google Shopping + maior número de anúncios na biblioteca do Facebook
- Quanto mais operações, mais real a saída

### 2. Para cada operação, capturar
- **Site:** print homepage + PDP (use GoFullPage)
- **Instagram:** padrão de fotos, sazonalidade, modelos, stories
- **Anúncios:** quantidade ativa na biblioteca, formato (vídeo/imagem/UGC)
- **Oferta:** preço e bundles principais
- **Audiovisual estrutural** (fixo) e de **GTM** (criativos)

### 3. Identificar padrões repetidos entre as operações
- Quanto mais marcas usam o mesmo elemento, mais essencial ele é
- Ex: 80% das operações têm fotografia autoral em fundo branco → isso é essencial

### 4. Aplicar [[04. Matriz Moscow para Decisão de Nicho|Matriz Moscow]]
- Deve ter (essencial)
- Deveria ter (gera vantagem)
- Pode ter (bom de bom)
- Não deve ter (descartado)

### 5. Decidir
Critérios de descarte automático:
- **Um item do "Deve ter" não está no seu alcance** → não execute
- Não consegue suprir os 5 critérios finais

## Validação
Você sabe que terminou bem quando consegue, com 1 olhada na Matriz Moscow, dizer:
- O esforço financeiro estimado (caixa)
- O tempo até primeiro pedido
- Quais riscos não consegue mitigar

## Erros comuns

| Erro | Correção |
|---|---|
| Analisar 1-2 operações apenas | Mínimo 10 — padrões só aparecem em volume |
| Usar referência sem comparar com tradicional | Sempre incluir 3-4 tradicionais |
| Confundir "deveria ter" com "deve ter" | "Deve ter" = quebra a operação se faltar |
| Querer começar com tudo do "deveria ter" | Pré-MVP só precisa de "deve ter" + algum "deveria ter" |
