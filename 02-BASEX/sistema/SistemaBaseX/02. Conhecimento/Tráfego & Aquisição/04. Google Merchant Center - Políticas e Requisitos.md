# Google Merchant Center - Políticas e Requisitos

> Base de conhecimento oficial e operacional sobre tudo que afeta aprovação no Google Merchant Center (GMC). Cobre Shopping Ads, Performance Max, Free Listings e Demand Gen. Fonte: documentação oficial do Google + experiência de campo em lojas Shopify.

---

## 1. Visão Geral - Por que GMC reprova

A maioria das reprovações cai em 6 buckets:

1. **Conformidade do site** - HTTPS, políticas faltando, contato ausente
2. **Conformidade do produto** - identificadores únicos, atributos obrigatórios, imagens
3. **Conformidade de preço e disponibilidade** - microdata vs site, frete, impostos
4. **Categorias proibidas/restritas** - produtos que violam política do Google
5. **Promoções enganosas** - claims, descontos falsos, antes/depois
6. **Discrepância entre feed e landing page** - preço, disponibilidade, moeda, GTIN

## 2. Requisitos do Site (homepage + páginas institucionais)

### 2.1 Obrigatórios

| Requisito | Critério | Como validar |
|-----------|----------|--------------|
| **HTTPS** | Todo o site sob certificado válido (não auto-assinado, não expirado) | curl -I + checar cadeia |
| **Domínio próprio** | Não usar `*.myshopify.com` direto. Subdomínio próprio OK | Verificar URL canônica |
| **Política de Devolução e Reembolso** | Visível, acessível em até 2 cliques da homepage | URL `/policies/refund-policy` |
| **Política de Privacidade** | LGPD/GDPR compliant. Inclui cookies, dados, retenção | URL `/policies/privacy-policy` |
| **Termos de Serviço** | Cobre disputas, jurisdição, propriedade intelectual | URL `/policies/terms-of-service` |
| **Política de Envio** | Prazos, países atendidos, custos, transportadora | URL `/policies/shipping-policy` |
| **Contato funcional** | Pelo menos 2 de: e-mail, telefone, formulário, endereço físico | Página `/pages/contact` |
| **Informação da empresa** | Razão social, CNPJ/NIF/VAT visível no rodapé ou Sobre | Rodapé + Sobre |
| **Idioma e moeda consistentes** | Site no idioma e moeda do país-alvo | Checar `<html lang>` e currency selector |
| **Checkout seguro** | Sem redirects suspeitos. Pagamentos visíveis com logos reconhecidos | Test purchase mode |

### 2.2 Recomendados (reduzem fricção)

- Selos de segurança (SSL, McAfee, Norton) visíveis
- Reviews/Trustpilot embedados (não fakes)
- Página "Sobre Nós" com história real e fotos da equipe (mesmo que pequena)
- FAQ com respostas reais
- Links de redes sociais ativas
- Política de cookies com banner (LGPD/GDPR)

### 2.3 Reprovações comuns de site

| Sintoma | Causa raiz | Correção |
|---------|------------|----------|
| "Insuficient contact information" | Falta telefone OU endereço físico | Adicionar em footer + página contato |
| "Misrepresentation of self or product" | Sobre-nós genérico/copiado, claims sem prova | Reescrever sobre + adicionar prova social real |
| "Insufficient/missing policies" | Faltando política específica | Criar todas as 4 policies obrigatórias |
| "Untrustworthy promotions" | Antes/depois sem prova, "frete grátis" enganoso | Remover claims sem base |
| "Editorial requirements" | Texto com erros gramaticais, caixa-alta abusiva | Revisão linguística |

## 3. Requisitos do Produto (feed + PDP)

### 3.1 Atributos obrigatórios

| Atributo | Detalhe | Erro comum |
|----------|---------|-----------|
| `id` | SKU único, persistente | Mudar SKU quebra histórico de performance |
| `title` | Até 150 chars, sem CAIXA ALTA, sem promo | "MELHOR PREÇO!!!" reprova |
| `description` | Mínimo 500 chars recomendado | Descrição copiada do fornecedor |
| `link` | URL da PDP, sem parâmetros UTM | Link quebrado = disapproval |
| `image_link` | URL absoluta, mínimo 250x250px, recomendado 800x800+ | Imagem com texto/watermark/borda |
| `availability` | `in stock` / `out of stock` / `preorder` | Discrepância com site |
| `price` | Formato `XX.XX BRL` ou `XX.XX EUR` | Moeda divergente do feed_label |
| `brand` | Marca real. Se white label/genérico, usar nome da loja | Faltando marca |
| `condition` | `new` / `refurbished` / `used` | Default `new` se omitido |
| `gtin` ou `mpn` | GTIN (EAN/UPC) preferido | Sem identificador único + sem brand = reprova |
| `google_product_category` | Categoria GPC oficial | Categoria errada = restrição |
| `identifier_exists` | `false` apenas para produtos sem identificador real (artesanal, custom) | Usar `false` indevidamente |

### 3.2 Identificadores únicos (GTIN/MPN)

| Cenário | O que usar |
|---------|-----------|
| Marca conhecida (Nike, Apple) | GTIN obrigatório |
| White label / marca própria | MPN + brand OK |
| Custom / artesanal / handmade | `identifier_exists: false` + brand |
| Bundle/kit | GTIN do principal OU MPN único |
| Vintage / antigo | `identifier_exists: false` + descrição clara |

**Regra de ouro:** se o produto existe em outra loja, ele tem GTIN. Procurar no Google Shopping pelo nome.

### 3.3 Imagens

| Requisito | Critério |
|-----------|----------|
| Tamanho mínimo | 250x250px (vestuário 500x500) |
| Tamanho recomendado | 800x800 a 1600x1600 |
| Formato | JPEG, PNG, BMP, GIF (não animado), TIFF, WebP |
| Fundo | Preferencialmente branco/neutro (não obrigatório, mas reduz reprovação) |
| Texto sobreposto | PROIBIDO (logo do site, "promoção", "novo", watermark) |
| Bordas | PROIBIDO bordas decorativas, frames |
| Múltiplos produtos | Imagem principal deve ter SÓ o produto vendido |
| Lifestyle | OK como imagem secundária, não como principal |
| Modelo/pessoa | OK para vestuário. Sem expressão sexualizada |
| Mockup/render | OK se realista. Render claramente falso reprova |

### 3.4 Título e descrição

**Título — formato ideal:**
```
[Marca] + [Nome do produto] + [Atributo chave] + [Tamanho/Cor]
Ex: Nike Air Max 90 Tênis Masculino Preto 42
```

**Proibido em título:**
- CAIXA ALTA (exceto siglas)
- Pontuação excessiva (!!!, ???)
- Emojis (com raras exceções)
- Texto promocional ("oferta", "barato", "grátis")
- HTML tags
- Idioma diferente do mercado-alvo

**Descrição — formato ideal:**
- Mínimo 500 chars
- Estrutura: parágrafo de abertura + bullets de specs + uso/benefício
- Sem CTA agressivo ("compre agora!")
- Sem URL de outros sites
- Sem informação de contato/promoção

### 3.5 Preço

| Regra | Detalhe |
|-------|---------|
| **Preço no feed = preço no site** | Tolerância zero. Discrepância = reprovação |
| **Moeda = moeda do feed_label** | Feed BR em BRL, feed PT em EUR |
| **Sale price** | Use `sale_price` separado. Preço normal vai em `price` |
| **Sale price effective date** | Indicar janela do desconto |
| **Frete embutido** | Se site tem frete grátis, declarar `shipping` no feed = 0 |
| **Imposto** | Incluído no preço (mercado BR/EU). Não somar VAT no checkout sem aviso |

### 3.6 Disponibilidade

| Status feed | Status site | Resultado |
|-------------|-------------|-----------|
| in stock | Botão "comprar" ativo | OK |
| in stock | "Esgotado" / "Sold out" | REPROVA |
| out of stock | Botão "comprar" ativo | REPROVA |
| preorder | Página dedicada com data de envio | OK |

**Atualização:** feed deve sincronizar disponibilidade a cada 24h no máximo. Shopify nativo já faz via app.

## 4. Categorias Proibidas (NUNCA aceitas)

| Categoria | Detalhes |
|-----------|----------|
| **Armas e munição** | Inclui réplicas realistas, peças de armas |
| **Drogas recreativas** | CBD em alguns mercados é permitido com restrição |
| **Falsificações** | Réplicas de marcas, knock-offs |
| **Conteúdo adulto** | Pornografia, brinquedos sexuais explícitos |
| **Produtos perigosos** | Explosivos, materiais radioativos |
| **Serviços financeiros enganosos** | Empréstimos predatórios, esquemas piramidais |
| **Hacking/spyware** | Software de invasão, key-loggers |
| **Animais vivos** | Exceção: rações e acessórios |
| **Tabaco e derivados** | Cigarro, vape, e-liquid em maioria dos mercados |
| **Documentos falsos** | Passaportes, diplomas, IDs |

---

## 5. Categorias Restritas (aceitas com condições)

| Categoria | Restrição |
|-----------|-----------|
| **Álcool** | Certificação de idade, alguns países proibidos, sem promoção a menores |
| **Apostas / gambling** | Certificação por país, alvará exigido |
| **Suplementos** | Não pode prometer cura, perda de peso milagrosa, ganho muscular extremo |
| **Cosméticos com claims** | "Anti-envelhecimento" OK; "elimina rugas em 7 dias" REPROVA |
| **Saúde e medicamentos** | Sem OTC sem prescrição em mercados regulados |
| **Saúde infantil** | Brinquedos com certificação de segurança (CE, INMETRO) |
| **Eletrônicos** | Certificação ANATEL (BR), CE (EU), FCC (US) |
| **Produtos personalizados** | OK, mas exigem `identifier_exists: false` + brand |
| **Reembolso financeiro / cashback** | Termos explícitos, sem promessa de retorno |

## 6. Promoções e claims (causa #1 de reprovação misrep)

### 6.1 Proibido em copy de produto ou site

- "Cura X doença"
- "Resultado garantido em N dias"
- "100% natural" sem certificação
- "Melhor do mercado"
- "Único produto que..."
- Antes/depois sem disclaimer e prova
- Preço riscado sem desconto real (Shopify "compare at price" precisa ser preço real anterior)
- Countdown timer falso ("acaba em 5 min" que reseta)
- "Estoque limitado" sem ser verdade
- Falsa urgência ("só hoje" repetido)

### 6.2 Permitido com cuidado

- Promoções reais com data de início/fim
- "Recomendado por X" se houver fonte verificável
- Comparação com concorrente apenas com dados factuais
- "Líder em vendas" se houver dado público

## 7. Schema Markup (microdata structured data)

GMC compara o feed com o que o robô vê no site. Schema bom = menos discrepância.

### 7.1 Schema obrigatório na PDP

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "...",
  "image": ["...", "..."],
  "description": "...",
  "sku": "...",
  "gtin13": "...",
  "brand": {"@type": "Brand", "name": "..."},
  "offers": {
    "@type": "Offer",
    "url": "...",
    "priceCurrency": "BRL",
    "price": "99.90",
    "availability": "https://schema.org/InStock",
    "itemCondition": "https://schema.org/NewCondition"
  }
}
```

### 7.2 Schema recomendado

- `aggregateRating` (se tem reviews reais)
- `review` (até 5 reviews destacados)
- `shippingDetails` (custo + prazo)
- `hasMerchantReturnPolicy` (vincula política de devolução)

### 7.3 Validar schema

- https://search.google.com/test/rich-results
- https://validator.schema.org/

## 8. Feed Shopify - Setup correto

### 8.1 App oficial

**Google & YouTube** (Shopify oficial) — gratuito, sincroniza catálogo via Merchant Center.

### 8.2 Mapeamento crítico

| Shopify campo | GMC atributo | Cuidado |
|---------------|--------------|---------|
| Product title | title | Sem promo, sem CAIXA ALTA |
| Product description | description | HTML é convertido em texto puro |
| Product type | google_product_category | Mapear pra GPC oficial |
| Vendor | brand | Não deixar "vendor" como string genérico |
| Barcode | gtin | Validar dígito verificador |
| SKU | mpn | Único por variante |
| Compare at price | sale_price + price | Inverte: price=compare, sale_price=current |
| Image | image_link + additional_image_link | Primeira é principal |
| Variant | item_group_id agrupa | Cores/tamanhos como variantes do mesmo grupo |

### 8.3 Erros comuns no Shopify

| Erro | Causa | Fix |
|------|-------|-----|
| GTIN inválido | Barcode com letras ou checksum errado | Validar EAN-13 |
| Preço diverge | Markets/multi-currency mal configurado | Sincronizar feed por mercado |
| Imagem genérica | Imagem de placeholder ainda no produto | Bulk update no admin |
| Categoria errada | "Standard product type" usado em vez de "Google product category" | Editar produto, definir GPC |
| Variante sem identificador | Cada cor/tamanho precisa GTIN/MPN próprio | Preencher por variante |

## 9. Performance Max e Shopping Ads (camada acima)

Mesmo com GMC aprovado, PMAX pode reprovar criativos/anúncios separadamente.

### 9.1 PMAX requisitos extra

- Logos da marca (1:1 + 4:1) em alta resolução
- Headlines (5+) sem CAIXA ALTA
- Long headlines (1+) até 90 chars
- Descrições (4+) até 90 chars
- Imagens 1.91:1 + 1:1 (sem texto sobreposto)
- Vídeo 10s+ (gerado automaticamente se não fornecido — mas reprova frequente)
- Sitelinks com URLs reais que carregam

### 9.2 Shopping Ads (CSS)

- BR: parceiros CSS dão desconto 20% no CPC
- EU: CSS obrigatório (Google Shopping vs CSS terceiro)
- Configurar no Merchant Center, vincular ao Ads

### 9.3 Reprovação no Ads (após GMC OK)

| Status | Causa | Onde corrigir |
|--------|-------|---------------|
| "Limited" | Algumas categorias restritas | Apelar com certificação |
| "Disapproved" | Política do Ads (não do feed) | Reescrever asset, recriar campanha |
| "Under review" | Aguardando | 1-3 dias normal, 7+ abrir ticket |

## 10. Processo de auditoria (passo a passo aplicado)

### Fase 1 - Site (homepage + institucional)
1. Carregar homepage e validar HTTPS
2. Ler rodapé: políticas, contato, info da empresa
3. Visitar cada política e verificar conteúdo real (não placeholder)
4. Validar página de contato com pelo menos 2 canais
5. Checar "Sobre Nós" — buscar evidência de empresa real

### Fase 2 - Produtos (amostra + crítica)
1. Listar 100% dos produtos via API/CLI
2. Para cada produto: título, descrição, imagens, GTIN, brand, categoria
3. Cruzar feed (se já existe) com PDP
4. Identificar padrões: faltam GTINs em massa? Imagens com watermark? Títulos em CAIXA ALTA?

### Fase 3 - Checkout
1. Adicionar item ao carrinho
2. Iniciar checkout (sem pagar)
3. Validar: moeda correta, frete calculado, impostos transparentes, sem redirect suspeito

### Fase 4 - Schema markup
1. Rodar Rich Results Test em 3-5 PDPs
2. Validar Product schema completo
3. Conferir se preço/disponibilidade no schema = no feed

### Fase 5 - Categorização
1. Para cada produto, validar GPC contra restrições
2. Identificar produtos potencialmente restritos (suplementos, cosméticos, etc.)
3. Marcar para review humano antes de enviar ao GMC

### Fase 6 - Relatório
Estrutura do output:
- Severidade: Crítico / Alto / Médio / Baixo
- Categoria: Site / Produto / Imagem / Preço / Categoria / Schema
- Item afetado: URL/SKU específico
- Política violada: nome oficial + link
- Correção exata: o que mudar e como

---

## 11. Severidade - como classificar

| Nível | Critério | Exemplo |
|-------|----------|---------|
| **CRÍTICO** | Bloqueia aprovação do GMC inteiro | Sem HTTPS, sem políticas, categoria proibida |
| **ALTO** | Reprova produtos individualmente | GTIN inválido, imagem com texto, preço diverge |
| **MÉDIO** | Reduz performance/quality score | Descrição curta, sem schema, título com promo leve |
| **BAIXO** | Polimento, não bloqueia | Sem reviews, sem badges de confiança |

## 12. Apelação (quando GMC já reprovou)

1. Corrigir o problema raiz primeiro
2. No Merchant Center: Produtos → Diagnóstico → Pedir nova revisão
3. Para conta toda reprovada: Conta → Solicitar revisão
4. Aguardar 2-7 dias úteis
5. Não solicitar revisões múltiplas sem correção (acumula peso negativo)

## 13. Mercados-alvo BaseX - especificidades

### Brasil
- Moeda: BRL
- VAT/IVA: incluído no preço
- Contato deve ter CNPJ visível
- LGPD compliance obrigatório

### Portugal/Espanha/União Europeia
- Moeda: EUR
- IVA incluído (regime OSS recomendado)
- GDPR compliance obrigatório
- Política de devolução conforme diretiva 2011/83/UE (14 dias)
- Endereço físico na EU recomendado (compliance + confiança)

### Reino Unido (pós-Brexit)
- Moeda: GBP
- VAT separado se vendedor não UK
- Cumprir UK GDPR (paralelo ao europeu)
