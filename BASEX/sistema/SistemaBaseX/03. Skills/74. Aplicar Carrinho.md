## Contexto

Aplica o **cart-drawer Buy More Save More** (variante Sound/Maestrooo) na sua loja Shopify, a partir do template pronto que vem no SistemaBaseX. Faz backup automático, adapta só a cor do header e o idioma, aplica numa cópia, valida e publica só após aprovação.

A fonte de verdade do código é o template [[cart-drawer-sound-maestrooo]]. Esta skill é o passo a passo executável.

Usar quando:
- "aplica o carrinho na loja X"
- "aplica o carrinho de descontos progressivos na minha loja"
- "instala o carrinho buy more save more na loja Y"

## Inputs

Perguntar ao usuário **antes de executar** (a menos que já estejam em `$ARGUMENTS`):

### Obrigatórios
1. **Loja alvo** - handle myshopify (ex: `nome-da-loja.myshopify.com`)

### Opcionais (perguntar só se relevante)
- **Idioma do copy** (default: detectar pelo locale da loja — espanhol, português, inglês)
- **Publicar agora?** (default: não — aplica só na cópia e publica no live após sua aprovação)

## Pré-requisitos

- Shopify CLI v3+ autenticado (`shopify store auth --store LOJA --scopes read_themes,write_themes`)
- Confirmar compatibilidade: o tema alvo precisa ter `sections/cart-drawer.liquid` autocontido tipo Sound/Maestrooo (`<cart-drawer>`, `v-stack`/`h-stack`, `slot="footer"`, snippet `price-list` com `original_line_price`/`final_line_price`). Se for Streetch/Dawn → usar [[cart-drawer-liquid]]. Se for Horizon → [[cart-drawer-horizon]].

## Passos de execução

### Passo 1 - Autenticar e identificar o tema live
```bash
shopify theme list --store LOJA.myshopify.com          # dispara login se preciso
shopify store auth --store LOJA.myshopify.com --scopes read_themes,write_themes
```
Anotar o ID do tema com role `[live]` (= `LIVE_ID`).

### Passo 2 - Detectar a base do tema
Puxar `sections/cart-drawer.liquid` + `config/settings_data.json` via Admin GraphQL (`themeFiles(filenames:)`) ou `shopify theme pull --only`. Confirmar que é Sound/Maestrooo (ver Pré-requisitos). Se não for, parar e indicar a variante correta.

### Passo 3 - Backup + cópia de trabalho
```bash
shopify theme pull --store LOJA --theme LIVE_ID --path ./tema-LOJA
shopify theme push --store LOJA --unpublished -t "LOJA - BMSM Cart" --path ./tema-LOJA --json
```
Guardar o ID da cópia (= `COPY_ID`). **Nunca editar o live direto.**

### Passo 4 - Ler a cor do header
De `config/settings_data.json` da cópia, pegar `current.header_background` (e `current.header_text_color`). Esse hex vira `--mb-primary`; converter pra RGB → `--mb-primary-rgb`.

### Passo 5 - Adaptar o template
Pegar o payload de [[cart-drawer-sound-maestrooo]] (bloco entre `BMSM-SOUND-CART-PAYLOAD-START/END`). Customizar **só 2 coisas**:
1. **Cor:** `--mb-primary` = header_background; `--mb-primary-rgb` = mesmo hex em R, G, B; ajustar `--mb-accent` p/ um tom mais claro se quiser.
2. **Idioma:** traduzir as strings (título "Compra más y ahorra", timer "Asegura tu pedido · Reserva:", "Descuentos", "Envío a {país}" / "Envío gratis", nota "Los descuentos se aplican automáticamente al pagar", aria "Métodos de pago") pro idioma da loja.

Salvar em `./tema-LOJA/sections/cart-drawer.liquid`.

### Passo 6 - Push na cópia + theme check
```bash
shopify theme push --store LOJA --theme COPY_ID --path ./tema-LOJA --only "sections/cart-drawer.liquid" --json
shopify theme check --path ./tema-LOJA      # cart-drawer.liquid deve ficar SEM ofensas
```
**Sempre `--only`** (ver [[05. Shopify Theme Push - Regras de Segurança]]). Corrigir ofensas no cart-drawer antes de seguir.

### Passo 7 - Validar com produto no carrinho
Numa sessão HTTP: ativar preview (`/?preview_theme_id=COPY_ID`), adicionar um produto (de preferência um com desconto/compare-at) via `/cart/add.js`, renderizar `/?section_id=cart-drawer` e conferir as classes `mb-bmsm__*`. Montar um HTML estático com o CSS do tema (`<base href>`) e tirar screenshot do drawer (a aba do live cai sozinha por causa do page-transition — renderizar local resolve). Conferir: timer translúcido, Descuentos verde (se houver desconto), Envío com país, Total, ícones de pagamento.

### Passo 8 - Publicar (só após aprovação)
Mostrar o screenshot e o preview (`https://LOJA.myshopify.com?preview_theme_id=COPY_ID`). Só depois do "ok":
```bash
shopify theme push --store LOJA --theme LIVE_ID --path ./tema-LOJA --only "sections/cart-drawer.liquid" --allow-live --json
```

### Passo 9 - Registrar no SistemaBaseX
Registrar em `06. Saídas/Loja/` uma nota com: base do tema, cor do header, IDs (live e cópia), data, e qual variante do template foi usada.

## Troubleshooting

| Erro | Causa | Solução |
|------|-------|---------|
| Linha de Descuentos não aparece | Nenhum produto com desconto/compare-at no carrinho | É esperado — a linha só renderiza com `(preço cortado − preço atual) > 0`. Lógica usa `max(original_line_price, compare_at×qty) − final_line_price`. |
| Aba do storefront fecha sozinha no browser | Page-transition do tema desanexa o contexto CDP | Validar via render estático local (HTML + CSS do tema + `<base href>`), não na aba do live. |
| `/cart/add.js` retorna desafio Cloudflare | Muitas requisições seguidas | Trocar pra POST `/cart/add.js` com User-Agent de browser; aguardar e repetir. |
| Bandeira não aparece (só "BR") | Windows desktop não renderiza regional-indicator emoji | Normal — renderiza em mobile/Mac/Android. |
| Push apagou arquivos do tema | Push sem `--only` de diretório parcial | NUNCA push sem `--only`. Ver [[05. Shopify Theme Push - Regras de Segurança]]. Restaurar do backup local. |
| Tema não é Sound/Maestrooo | Markup do cart-drawer diferente | Usar a variante certa: Streetch → [[cart-drawer-liquid]]; Horizon → [[cart-drawer-horizon]]. |
