# Ambiente Claude

Esta é a pasta que o dono da loja conectou no Claude. O SistemaBaseX, com o conhecimento, as habilidades e as ferramentas da BaseX, fica em:

{{SISTEMA}}

Todo caminho citado nas instruções abaixo e nas habilidades (`_brain`, `00. Comece Aqui.md`, `02. Conhecimento`, `03. Skills`, `04. Templates`, `05. Guias`, `06. Anexos`, `06. Saídas`, `Minhas Lojas`, `_engine`) fica dentro dessa pasta. Leia e grave lá, com o caminho completo. Para rodar uma ferramenta de `_engine`, entre antes na pasta do sistema e rode o comando exatamente como a habilidade mostra, sem aspas no caminho da ferramenta, por exemplo `cd "{{SISTEMA}}" && node _engine/acervo-nichos/preflight.mjs`. É assim que as permissões da BaseX reconhecem o comando e ele roda sem pedir aprovação.

Esta pasta é a central do Claude: os documentos de trabalho dele ficam aqui. O que uma habilidade manda salvar vai para o lugar que ela indica, dentro do SistemaBaseX.

Este arquivo é gerado pelo instalador a partir do CLAUDE.md do SistemaBaseX, que vem logo abaixo. Não edite: para atualizar, rode o instalador de novo.
