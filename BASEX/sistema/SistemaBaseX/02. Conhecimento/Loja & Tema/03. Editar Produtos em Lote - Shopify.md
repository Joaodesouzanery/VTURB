## O que e

Sistema de edicao em lote de produtos Shopify usando o script `product_editor.py` via Shopify CLI. Nao requer API key extra - o Claude Code da sessao faz o processamento de IA.

Repositorio do script: `.claude/skills/shopify-product-editor/`

---

## Operacoes disponiveis

### Sem IA (direto via CLI)

| Comando | Descricao |
|---------|-----------|
| `divide-price --factor 5 --compare-discount 60` | Divide preco por 5, compare_at com 60% de desconto aparente |
| `compare-at-price --discount 60` | Apenas seta compare_at (sem mudar preco) |
| `set-price --value 99.90` | Define preco fixo em todos |
| `fix-sizes` | Traduz tamanhos BR→EN (P→S, G→L, GG→XL) |
| `fix-option-values` | Traduz cores, signos, materiais PT→EN |
| `set-vendor --vendor "Marca"` | Define fornecedor |
| `replace-brand --old X --new Y` | Substitui marca nos titulos |
| `set-alt-text --brand "Marca"` | Define alt text das imagens |
| `convert-sizes` | Converte tamanhos BR→EU numericos |
| `convert-webp` | Converte imagens para WebP |
| `add-tags --tags "a,b"` | Adiciona tags |
| `set-status --status ACTIVE` | Ativa/arquiva produtos |

### Com IA (traducao + SEO/GEO)

**Fluxo de 3 passos:**
1. `export-for-ai --operation translate --lang "english" --brand "Marca"` → gera `/tmp/shopify_ai_input.json`
2. Claude Code processa e gera `/tmp/shopify_ai_output.json`
3. `apply-ai-results --file /tmp/shopify_ai_output.json` → aplica na Shopify

## Regras de Descricao SEO/GEO

Toda descricao gerada segue esta estrutura HTML obrigatoria:

```html
<h1>[Produto] - [Material] | [Marca]</h1>

<p>[Resumo GEO - 2-3 frases autocontidas para IAs indexarem]</p>

<h2>Por que escolher [material/diferencial]?</h2>
<ul>
  <li><strong>Brilho Radiante:</strong> ...</li>
  <li><strong>Durabilidade Superior:</strong> ...</li>
  <li><strong>Conforto Hipoalergênico:</strong> ...</li>
  <li><strong>Design Versatil:</strong> ...</li>
</ul>

<h2>Guia de Medidas / Como usar</h2>
<ol>
  <li><strong>Passo 1:</strong> ...</li>
</ol>

<h2>Cuidados e Manutencao</h2>
<ul>...</ul>

<h2>Frequently Asked Questions</h2>
<ul>
  <li><strong>Pergunta 1?</strong><br>Resposta direta.</li>
  <li><strong>Pergunta 2?</strong><br>Resposta direta.</li>
  <li><strong>Pergunta 3?</strong><br>Resposta direta.</li>
  <li><strong>Pergunta 4?</strong><br>Resposta direta.</li>
</ul>
```

> **NAO incluir** garantia, frete gratis, prazo de envio, politica de troca, suporte ao cliente, "hassle-free shopping" na descricao do produto. Essas informacoes vao no footer/politicas da loja (`/policies/refund-policy`, `/policies/shipping-policy`), nunca dentro do `descriptionHtml`. Padrao "Compra Garantida e Entrega Segura" foi REMOVIDO em 2026-05-13 apos feedback de cliente (chat Belmont).

### Principios SEO/GEO

| Regra | Detalhe |
|-------|---------|
| H1 obrigatorio | Sempre comeca com `<h1>` contendo nome + material + marca |
| Resumo GEO | 1o `<p>` e "executive summary" para IAs (Gemini, Perplexity, ChatGPT) |
| Entidades tecnicas | "Prata 925 Esterlina" nao "prata 925"; "Couro Legitimo" nao "couro" |
| Palavras-chave de intencao | hipoalergenico, durabilidade, versatil, resistente, premium |
| Negritos estrategicos | `<strong>` nos atributos principais |
| Vender antes do guia | Beneficios SEMPRE antes do guia de medidas |
| Marca no corpo | Mencionar {brand} pelo menos 1x no texto |
| Garantia ampliada | 14 dias (mais forte que 7) |
| Minimo 200 palavras | Para ranquear no Google |
| **handle no output** | **OBRIGATORIO incluir `handle: slugify(title)` em todo output `translate` e `seo-generate`.** Se o titulo muda (rename de marca) e o handle nao vai no JSON, a URL antiga permanece — ex: `/products/marca-antiga-teal-meridian` mesmo apos rename para `Marca Nova Teal Meridian`. Script `product_editor.py` auto-gera `slugify(title)` quando handle nao vem no JSON (fallback de seguranca). |
| **FAQ no final** | Ultima secao da descricao e `<h2>Frequently Asked Questions</h2>` com 4 perguntas relevantes. Substitui o antigo bloco "Compra Garantida e Entrega Segura". |
| **NUNCA politicas na descricao** | FORBIDDEN: garantia, frete, prazo, devolucao, suporte. Vai no footer/politicas, NUNCA no `descriptionHtml`. |
| **Classificacao por product_type** | Para coleções Men's/Women's, **usar `product_type`** como fonte de verdade, NUNCA o titulo sozinho. Titulos como "Belmont Vienne" nao contem genero — usar `product_type: "Women's Watch"`. Se product_type vazio, deixar produto SEM colecao e reportar como UNCATEGORIZED. |
| **collectionAddProducts one-by-one** | Batch falha quando algum produto ja esta na colecao. Script atual faz add um por um automaticamente, tratando duplicado como soft success. |
| **Colecoes auto-publicadas no Online Store** | `_ensure_collection` chama `publishablePublish` apos criar — sem isso a colecao fica oculta na storefront. |
| **Validacao pos-apply** | Script re-consulta 5 produtos de amostra apos `apply-ai-results` e compara title/vendor/seo. Se houver mismatch, alerta. Nunca reportar "ok" sem ver o resultado da validacao. |

## Colecoes e Canais de Vendas

Quando o script cria uma colecao nova (`collectionCreate`), ela e automaticamente publicada no canal **Online Store (Loja Virtual)** via mutation `publishablePublish`. Isso e necessario para que a colecao apareca disponivel para adicionar ao menu principal da loja.

**Apos as colecoes serem criadas:**
Admin Shopify → Loja Virtual → Navegacao → Menu principal → Adicionar item → escolher as colecoes

O script detecta o canal Online Store automaticamente pelo nome (busca por "online" ou "loja virtual" na lista de publicacoes da loja).

## Divisao de Precos

```
new_price   = floor(original / factor * 10) / 10   → termina em X.X0
compare_at  = ceil(new_price / (1 - desconto%) * 10) / 10

Exemplo (factor=5, desconto=60%):
  149,90 / 5 = 29,98 → 29,90
  29,90 / 0,40 = 74,75 → 74,80
  Desconto aparente: (74,80 - 29,90) / 74,80 = 60% ✓
```

## Fluxo Completo para Loja Importada

```bash
SCRIPT=.claude/skills/shopify-product-editor/scripts/product_editor.py
STORE=minha-loja.myshopify.com
BRAND="Minha Marca"

# 1. Autenticar
shopify store auth --store $STORE \
  --scopes "read_products,write_products,read_files,write_files"

# 2. Precos
python3 $SCRIPT $STORE divide-price --factor 5 --compare-discount 60

# 3. Traducao + SEO/GEO + Colecoes
python3 $SCRIPT $STORE export-for-ai --operation translate \
  --lang "english" --brand "$BRAND"
# → Claude Code gera /tmp/shopify_ai_output.json
python3 $SCRIPT $STORE apply-ai-results --file /tmp/shopify_ai_output.json

# 4. Correcao de opcoes
python3 $SCRIPT $STORE fix-sizes
python3 $SCRIPT $STORE fix-option-values
```
