### 1.3 Settings Globais do Impact (principais)

Configurados via `config/settings_schema.json`:
- **Tipografia:** fontes de heading e body, tamanho base
- **Cores:** background, texto, botoes (primario/secundario), links, bordas
- **Gradientes:** suporte nativo a gradientes em backgrounds e headings
- **Botoes:** estilo (filled/outlined/text), borda, sombra, hover
- **Imagens:** lazy load, placeholders
- **Spacing:** padding de sections (compacto/normal/amplo)
- **Badge:** estilo de badges de produto (sale, new, etc.)

### 1.4 Capacidades Especiais do Impact

- **Parallax:** disponivel em image-with-text-overlay, slideshow, collection-banner
- **Transparent header:** disponivel em slideshow, image-with-text-overlay, video, collection-banner
- **Stack on mobile:** maioria das sections tem controle separado para mobile
- **Show carousel progress bar:** em collection-list, featured-collection, recently-viewed
- **Full width toggle:** quase todas as sections tem opcao de full-width ou container
- **Remove vertical/horizontal spacing:** em custom-html, custom-liquid, apps
- **Gradientes em textos:** headings com gradient nativo
- **Swatches:** suporte a swatches de cor/tamanho na grade de produtos
- **Sticky header com hide on scroll:** configuravel no header
- **Mega menu:** suporte a mega menus com promocoes e imagens
- **Shipping estimator:** no cart
- **Free shipping bar:** snippet disponivel

## 4. Criacao de Sections Customizadas (Shopify Theme Editor Controlavel)

Quando o tema nao tem a section necessaria, criar uma nova section Liquid que seja 100% controlavel pelo editor de temas (sem precisar editar codigo apos criacao).

### Principios de uma section controlavel pelo editor

1. **Tudo via `{% schema %}`** - cada elemento configuravel deve ter um setting
2. **Tipo de setting correto** para cada dado:
   - Texto curto: `type: "text"`
   - Texto longo: `type: "textarea"` ou `type: "richtext"`
   - Imagem: `type: "image_picker"`
   - Video: `type: "video"` (hosted) ou `type: "url"` (YouTube/Vimeo)
   - Cor: `type: "color"`
   - Select: `type: "select"` com `options:`
   - Range: `type: "range"`
   - Checkbox: `type: "checkbox"`
   - URL/Link: `type: "url"`
   - Colecao: `type: "collection"`
   - Produto: `type: "product"`
   - Blog: `type: "blog"`
   - Pagina: `type: "page"`
   - Liquid customizado: `type: "liquid"` (Shopify 2.0+)
3. **Blocks para conteudo repetido** - evitar settings duplicados (ex: items de FAQ, logos, etc.)
4. **Presets** - definir preset default para que o comerciante encontre facilmente no editor
5. **`max_blocks`** - limitar numero de blocks quando necessario
6. **`disabled_on`** - restringir onde a section pode aparecer se necessario
7. **Nomes em portugues** - usar `label:` em portugues nos settings

### Estrutura padrao de uma section custom

```liquid
{%- comment -%} Section: [Nome da Section] {%- endcomment -%}

<div class="section-[slug] {{ section.settings.color_scheme }}"
  style="padding-top: {{ section.settings.padding_top }}px; padding-bottom: {{ section.settings.padding_bottom }}px">
  
  {%- if section.settings.heading != blank -%}
    <h2>{{ section.settings.heading | escape }}</h2>
  {%- endif -%}

  {%- for block in section.blocks -%}
    {%- case block.type -%}
      {%- when 'item' -%}
        <div {{ block.shopify_attributes }}>
          {%- if block.settings.image != blank -%}
            {{ block.settings.image | image_url: width: 800 | image_tag }}
          {%- endif -%}
          <h3>{{ block.settings.title | escape }}</h3>
          <p>{{ block.settings.text }}</p>
        </div>
    {%- endcase -%}
  {%- endfor -%}
</div>

{% schema %}
```

## 5. Identificar qual tema esta em uso

Ao receber acesso a uma loja, verificar:

```bash
# Via Shopify CLI
shopify theme list --store minha-loja.myshopify.com

# Verificar sections no tema ativo
cat sections/header.liquid | grep -i '"name"' | head -3
```

- Presenca de `shopify-section--impact-text` = Impact
- Presenca de `shopify-section--image-banner` sem `image-with-text-overlay` = Dawn
- `"theme_author": "Your Mama"` no settings_schema = Impact
- Ausencia de `before-after-image.liquid` = provavelmente Dawn
