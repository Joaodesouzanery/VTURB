# Tema Shopify - Streetch (A Stretch)

> Mapa completo de sections, blocks, settings e capacidades do tema Streetch. Usar como referencia ao recomendar, configurar ou criar sections em lojas que usam este tema.

---

## 1. Informacoes do Tema

**Nome tecnico:** A Stretch
**Versao:** 1.0.0
**Author:** Maestrooo
**Estilo:** Moderno, editorial, premium. Focado em moda/lifestyle. Muitas opcoes de layout e esquemas de cor.
**Diferenciais vs Impact/Dawn:**
- **Dynamic Grid** (grid livre de imagens/videos como moodboard editavel)
- **Countdown timer** nativo com comportamento configuravel apos expirar
- **Reading Text** (imagem com texto em parallax scroll progressivo)
- **Text with Fixed Background** (parallax com fundo fixo)
- **Scrolling Content** (marquee com texto + imagens + separadores)
- **Products with Image** (produtos ao lado de imagem decorativa)
- **Featured Links** (links estilizados com hover de cor)
- **Specifications** (tabela de especificacoes tecnicas do produto)
- **Trust Icons** (icones de confianca/beneficios)
- **Media Blocks** (grid de midias com blocos configurados)
- **Age Verifier Popup** (verificador de idade)
- **Blocks externos** em pasta `/blocks/` (arquitetura Shopify 2.0 avancada)
- **Mega menu** com suporte a promocoes

## 4. Diferenciais vs Impact e Dawn

### O que o Streetch tem que Impact NAO tem

| Funcionalidade | Section Streetch | Equivalente Impact | Equivalente Dawn |
|---------------|------------------|--------------------|-----------------|
| Dynamic grid livre | `dynamic-grid` | Parcial: `media-grid` | Criar custom |
| Countdown timer | `countdown` / `countdown-condensed` | Criar custom | Criar custom |
| Reading text (parallax scroll) | `reading-text` | Nao tem | Criar custom |
| Text fixed background (parallax) | `text-with-fixed-background` | Nao tem | Criar custom |
| Products with image decorativa | `products-with-image` | Nao tem | Criar custom |
| Featured links estilizados | `featured-links` | Nao tem | Criar custom |
| Specifications table | `specifications` | `feature-chart` (similar) | Criar custom |
| Trust icons | `trust-icons` | `text-with-icons` (similar) | Criar custom |
| Age verifier popup | `age-verifier-popup` | Nao tem | Criar custom |
| Blocks externos (`/blocks/`) | Arquitetura avancada | Nao tem | Nao tem |
| Scrolling content com imagens | `scrolling-content` | `scrolling-text` (so texto) | Criar custom |
| Media blocks grid | `media-blocks` | `media-grid` (similar) | Criar custom |

### O que Impact tem que Streetch NAO tem

| Funcionalidade | Section Impact |
|---------------|----------------|
| Impact text (texto gigante animado) | `impact-text` |
| Images with text scrolling (sticky) | `images-with-text-scrolling` |
| Revealed image on scroll | `revealed-image-on-scroll` |

## 6. Identificar Streetch em uma Loja

```bash
# Via settings_schema.json
python3 -c "import json; d=json.load(open('config/settings_schema.json')); print(d[0].get('theme_author',''))"
# Retorna: A Maestrooo

# Via presenca de sections unicas
ls sections/ | grep -E "dynamic-grid|reading-text|age-verifier"
```

- Presenca de `dynamic-grid.liquid` = Streetch
- `theme_author: A Maestrooo` = Streetch
- Pasta `/blocks/` com `_dynamic-grid-item.liquid` = Streetch
