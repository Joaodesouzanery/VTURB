# Lifestyle Copy vs Funcional Copy

## Definição
Duas abordagens opostas de copywriting em e-commerce, cada uma adequada a um perfil diferente de público e produto.

## Por que importa
Usar a copy errada pra a persona = repulsa. Persona high-ticket rejeita copy massiva persuasiva. Persona funcional precisa do "mastigado".

## Comparativo direto

|  | Lifestyle Copy | Funcional Copy |
|---|---|---|
| **Caso real** | **Halo** (vestuário fitness premium) | **Numoia** (escova portátil, produto) |
| **Público** | Classe A, high-ticket, exclusividade | Mais velho, prático |
| **Arquétipo** | Governante / Amante / Sábio | Cuidador / Cara Comum |
| **Texto** | Mínimo, curto | Extenso, mastigado |
| **Espaço em branco** | Muito | Pouco |
| **Persuasão explícita** | Quase zero | Heavy (timer, contador, prova social) |
| **Foco** | Lifestyle, comunidade | Benefício prático, oferta |
| **Ticket** | Alto | Médio/baixo |
| **Banner com oferta?** | Não, banner conceitual | Sim, com desconto destacado |
| **Pesos visuais** | Hierarquia minimalista | Hierarquia explícita |

## Por que funciona

### Lifestyle (Halo)
- Cliente tem capital alto, está acostumado com comunicação premium
- **Persuasão massiva = estranheza** (cria resistência)
- Quer entender se a marca representa quem ele é
- Compra **lifestyle**, não produto

> "A copy só precisa ser extensa quando a operação é falha."

### Funcional (Numoia)
- Cliente quer **prova de que funciona** antes de comprar
- Manada / sense espelho — quer ver outros usando
- Precisa quebrar objeção antes de seguir adiante
- Compra **resultado** (cabelo de salão, escovado em 5min)

## Elementos típicos de cada

### Lifestyle copy tem
- Imagem conceitual (pessoa em ambiente desejável)
- Texto curto, fonte fina
- Sem timer, sem contador
- Sem texto de descrição em parágrafo grande
- Espaço em branco generoso

### Funcional copy tem
- Banner de oferta com %off
- **Timer conservador** (4h, NÃO 15min — 15min cria resistência)
- Prova social com fotos reais
- Bullets de benefícios
- Quebra de objeção descarada (FAQ extenso)
- Senso de manada explícito ("X pessoas compraram esta semana")

## Como decidir qual usar

```
Persona high-ticket exclusividade? → Lifestyle
Persona funcional prática prova? → Funcional
Persona médio? → Híbrido (mais perto da funcional)
```

## Anti-pattern crítico

> "Imagina uma pessoa com capital alto, embasamento bom, comunicação premium. Ela entra numa construção feita pra ela e tem copy justificando e persuadindo demais. Vai sentir estranheza."

## Princípio inegociável

> **"Vender não é convencer. Vender é dispor clareza pra quem já quer comprar."**

## Quando aplicar
- Definir estilo na PDP, criativo, anúncio
- Antes de escrever primeira copy
