# Catálogo de Tipos de Criativo

## Definição
Inventário completo dos tipos de criativo usados em e-commerce/dropshipping, com quando cada um funciona melhor.

## Por que importa
Diferentes tipos têm impactos diferentes. **Operação madura tem múltiplos tipos rodando juntos** — cada cliente é impactado por tipos diferentes na jornada.

## Tabela completa

| Tipo | Subtipo | Quando funciona | Esforço |
|---|---|---|---|
| **Estático** | Foto + oferta simples | Padrão diário | Baixo |
| | Visual + lifestyle | Marca premium | Médio |
| | Mocap (catálogo) | Várias variações de produto | Médio |
| **Vídeo** | Profissional | Marcas premium, ticket alto | Alto |
| | UGC / GC | Anúncio mascarado de orgânico | Médio |
| | VSL (especialista) | Educar + qualificar | Médio |
| **IA** | Tendência (Ghibli, BB Reborn) | Pegar onda momentânea | Baixo |
| | Mocap IA | Variações de imagem | Baixo |
| **TikTok** | Meme / POV | Conteúdo orgânico mascarado | Baixo |
| **Sazonal** | Black/Natal/Pais/aniversário | Justificar oferta | Médio |

## UGC / GC — Quem produz

| Quem | Como | Custo |
|---|---|---|
| **Cliente** | Cashback (R$100 pra gravar com criança) | Baixo |
| **Creator profissional (GC)** | Paga por vídeo | Médio |
| **Influenciador** | Permuta + produto | Custo do produto + envio |
| **Dono fingindo cliente** | Caso Rafael Paloski (relógios) | Tempo |

## Anti-pattern: vídeo profissional como único

> "Vídeos muito profissionais nem sempre convertem mais — geram contraste com conteúdo orgânico do feed. Cara está vendo conteúdo 'podre' (entretenimento), do nada vê algo super produzido = fala 'isso é anúncio' e pula."

## Princípio: portfólio diverso

Operação madura roda **múltiplos tipos simultâneos**:
- Cliente é impactado por tipos diferentes
- Cada tipo qualifica de um jeito
- Mata o que não performa, mantém o que dá lucro

## Iluminação, cenário, composição

**Sem equipamento profissional?**
- **Sol** = melhor iluminação grátis
- **iPhone (mesmo modelo médio)** = qualidade suficiente

**Cenário:** combinar com produto. Não gravar relógio elegante no quarto.

**Composição (cenário fechado):** elementos como madeira, couro, sazonais (Natal: gorrinho, pisca-pisca, galhos artificiais com nevezinho).

## Multiplicação de variações

> "1 criativo validado → 50 variações. Caso One Million Club: cara testava 40+ criativos/dia, mas eram VARIAÇÕES de poucos validados."

Variar:
- 1 palavra do hook
- 1 cena
- 1 ângulo de câmera
- 1 CTA
- 1 música
- 1 trecho de copy

## Sazonal — Justificativa de oferta

Sempre **justificar a oferta** com sazonalidade:
- "X% off porque é Black"
- "X% off porque Natal"
- "X% off porque aniversário da loja"
- "X% off porque dia dos pais"

Inclusive **criar sazonalidade** (semana da marca, dia da loja).

## Quando aplicar
- Planejamento mensal de criativos
- Definir mix do mês
- Compensar criativo morrendo com tipo novo
