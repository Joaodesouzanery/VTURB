[[Objetivos de Campanha]]

- **O que é:** Este objetivo foca em direcionar visitantes para uma página específica, como seu site ou loja.
    
- **Exemplo prático :** Você pode usar esse objetivo para atrair visitantes para a página de um produto popular, como um Relógio. O anúncio pode ter uma chamada como "Descubra o Relógio que está transformando o estilo de milhares de pessoas! Clique para saber mais."
-  Esse objetivo provavelmente não vai te trazer vendas
