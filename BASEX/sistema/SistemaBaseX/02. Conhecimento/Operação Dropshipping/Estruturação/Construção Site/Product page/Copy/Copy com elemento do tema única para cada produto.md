[[Copy]]


Para incrementar o nível de navegação do usuário a copy do produto deve ser executada tal qual uma home page, ou seja, com cada elemento que o tema nos disponibiliza para construção do nosso site. Pode adicionar um banner, elementos clicáveis, etc... 

No exemplo abaixo trago um exemplo de elemento com rolagem lateral que guiam o usuário sem pesar verticalmente na extensão da copy:

!Pasted image 20250227182917.png

Para conseguir executar o máximo que seu tema disponibiliza e permitir executar copys com todos os elementos possíveis é necessário executar da seguinte forma: 

!Pasted image 20250227183342.png

Entre em personalizar tema.

!Pasted image 20250227183426.png
!Pasted image 20250227183449.png
!Pasted image 20250227183507.png
!Pasted image 20250227183623.png
!Pasted image 20250227183755.png

A partir do botão de adicionar sessão você pode visualizar quais elementos o seu tema permite que use para construir sua copy, tal qual sua home page.  

Neste momento esse modelo criado não esta vinculado a nenhum produto, por isso ao criar um modelo o produto que estava em tela troca para outro. Você pode executar toda a personalização e salvar, ela ainda não será disposta em nenhum local do seu site ativo. 

Para vincular essa copy de um produto único ao seu respectivo produto você deve sair da área de edição do tema, ir para Produtos, desce o scroll lateral até a última opção da coluna da direita:

!Pasted image 20250227184051.png

Aqui você vincula a copy ao seu produto.
