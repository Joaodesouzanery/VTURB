# Glossário VTURB / BaseX

Termos que as legendas automáticas costumam errar ou que aparecem muito nos vídeos.

| Termo | Significado |
|---|---|
| VSL | Video Sales Letter: vídeo de vendas |
| Nutra | Nutracêuticos (suplementos) |
| Native Ads | Anúncios nativos (Taboola, Outbrain etc.) |
| Low ticket / High ticket | Produto de ticket baixo / alto |
| Perpétuo | Venda contínua, sem janela de lançamento |
| CPA | Custo por aquisição; CPA de empate = CPA máximo sem prejuízo |
| CPM / CPC / CTR | Custo por mil impressões / por clique / taxa de clique |
| Bid cap | Limite de lance no Meta Ads |
| Hook / CTA | Gancho dos primeiros segundos / chamada para ação |
| UGC | Vídeo de pessoa comum usando o produto |
| LTV | Valor do cliente ao longo do tempo |
| Top spender | Anúncio que concentra a maior parte do gasto |
| BM | Business Manager (Gerenciador de Negócios do Meta) |
| SDE | Segredos da Escala (série da VTURB) |
| 8D / 7D | 8 dígitos / 7 dígitos de faturamento |
| MM | Milhões |

Correções a conferir nas transcrições: nomes de convidados, "VTurb"/"V-Turb" = VTURB, "vsl" = VSL.
